1. VISÃO GERAL
================================================================================

Blog editorial pessoal do Paul Gomes (paulgomes.com.br), publicado como site
estático. O conteúdo são ensaios sobre branding, tecnologia, IA, GEO, SEO e
arquitetura digital. Atualmente são 115+ ensaios migrados do blog antigo.

Posicionamento da marca:
  - Nome: Paul Gomes — Thinking Forward
  - Tagline: Branding · Tecnologia · Negócios
  - Voz: editorial, autoral, sem fórmula
  - Cor de destaque: ciano #00b4d8 (light) / #00d2d3 (dark)


================================================================================
2. STACK TÉCNICA
================================================================================

Framework:       Astro 6.3 (output: static, build em /dist)
CSS:             Tailwind CSS 4.3 via @tailwindcss/vite
Tipografia:      Montserrat (todos os pesos 100-900 + italic 400/700)
                 via @fontsource/montserrat
Conteúdo:        MDX (@astrojs/mdx)
Sitemap:         @astrojs/sitemap (gera /sitemap-index.xml)
RSS:             @astrojs/rss (feed em /rss.xml)
Imagens:         sharp ^0.34.3 (otimização automática Astro Image)
Node:            >=22.12.0
Repositório:     github.com/paulgomes/paulgomes-blog
Hospedagem:      Cloudflare Pages (deploy automático em push pra main)
Domínio:         paulgomes.com.br

12. COMO RODAR LOCALMENTE
================================================================================

Requisitos:
  Node 22.12.0 ou superior
  npm

Setup:
  cd paulgomes-blog
  npm install

Comandos:
  npm run dev          Servidor de desenvolvimento em localhost:4321
  npm run build        Build de produção em /dist
  npm run preview      Preview do build local
  npm run favicons     Regenera favicons a partir de public/favicon-source.png

Deploy:
  Push pra branch main → Cloudflare Pages dispara build e deploy
  automaticamente em ~1-2 min. Não precisa rodar nada localmente.
